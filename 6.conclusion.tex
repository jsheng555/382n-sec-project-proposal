\section{Conclusion}

This project will investigate whether information displayed by a protected webpage can be indirectly reconstructed through browser rendering side channels. We will build a controlled malicious and victim webpage environment, attempt to recover known visual information, and evaluate the accuracy, reliability, and time required for recovery.

A complete reconstruction of arbitrary webpages is not required for the project to be successful. If the basic attack is successful early enough, we will explore more difficult scenarios and implement persistent recovery so that an attacker could continue collecting information across multiple visits to the malicious webpage.
